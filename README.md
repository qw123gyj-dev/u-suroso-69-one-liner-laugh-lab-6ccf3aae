# One-Liner Laugh Lab

One joke, one sentence, one line. `main.ts` writes it to `entry.txt`, enforcing every gate — non-empty, at most 200 characters, exactly one sentence ending in a single period — then reads the file back and verifies the bytes match.

The prompt is the excuse a robot vacuum gives after eating a sock:

> "I ate the sock because it was on the floor — I'm a vacuum, not a sock detective."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-suroso-laugh-out node main.ts
```
